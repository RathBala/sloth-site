Connected accounts and sharing

Connected agents, API and CLI

Connecting an agent or creating an API token lets that tool access the Sloth data covered by its permissions. New connections and tokens are view-only by default. Allow changes only for a tool you trust and review proposed changes before approving them.

Write permission can let a tool change supported planning records, including budgets, goals, transaction categories and sharing settings. The API checks permissions, but cannot determine whether a conversation with an external agent represents your approval. Check important saved changes in Sloth.

You can disconnect an agent or revoke an API token in Settings. Hosted agent connections expire after 30 days unless you reconnect. API tokens follow the expiry shown when you create them.

Your chosen agent provider receives the results it requests within the access you allow and applies its own terms and privacy policy. The connection page explains when verified-email access is requested. Read those details before connecting.
